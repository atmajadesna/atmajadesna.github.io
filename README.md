# Atmaja Desna Adinata — Portfolio

A personal portfolio and collection of small browser applications built with HTML, CSS, and vanilla JavaScript.

[Visit portfolio](https://atmajadesna.github.io)

## Features

- Project catalogue with links to source repositories and demos.
- Light and dark themes with a saved preference.
- Responsive navigation and section highlighting.
- Scroll reveals with reduced-motion overrides.
- Embedded learning demos under `projects/`; existing routes are preserved.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. No framework build is required.

## Structure

- `index.html`: portfolio content.
- `style.css`: existing layout and themes.
- `refinement.css`: readability, focus, touch targets, and restrained color refinements.
- `script.js`: navigation, themes, and scroll behavior.
- `projects/`: standalone learning applications.

## Scope

This GitHub Pages portfolio is separate from the newer personal site. Linked applications may be simulations or backend prototypes; consult each project's setup and limitations before use. UI polish does not establish production readiness or security certification.
